# Расширение для трубопроводов — 8 октября 2026

Добавлено в существующий AutoCAD Engineering MCP 0.2.0. Используются прежний
stdio-сервер, конфигурация, CadService, блокировка рабочего процесса, единый
STA-поток COM и формат Result. Новый сервер и AutoCAD-плагин не требуются.

## Технические пределы

Все параметры новых инструментов используют единицы чертежа, WCS XY.
Поддерживаются LINE, LWPOLYLINE и simple POLYLINE при нулевой Elevation и стандартной
Normal. Fitted/splined и наклонные полилинии отклоняются. Arc bulges учитываются при
чтении и анализе; изменения маршрута с дугами запрещены, перенос сохраняет дуги.
LINE остаётся LINE: нельзя сохранить его Handle и одновременно сделать ломаный маршрут.

CONNECTED определяется только точными совпадениями конечных точек. Создаваемый
мостик имеет такие соединения на концах; топология сети и диаметры не назначаются
автоматически. Подключение к середине сегмента требует отдельного явного редактирования.
RED_PIPE/BLUE_PIPE — кандидаты, без определения отопления/водоснабжения.

Нет полной транзакции базы DWG: ActiveX предоставляет Undo marks и операции над
объектами. Реализовано компенсирующее восстановление снимков для редактирования,
но сбой COM может помешать восстановлению. Result сохраняет сведения об откате.
Удалённый объект не восстанавливается с прежним Handle программно; при ошибке
после Delete возвращается `unavailable_for_delete`, требуется проверка и AutoCAD Undo.
Приложение не вызывает Undo через SendCommand и не сохраняет DWG автоматически.

Межобъектный COM-анализ использует IntersectWith; математические self-intersections
не создают временную геометрию. Совпадающие участки и поведение конкретной версии
API требуют проверки на Windows. Анализ и подписи ограничены по числу кандидатов,
вершин, сравнений, тексту и размеру ответа. У запросов raw-пагинация, у анализа —
пагинация находок; при изменении DWG страницы нужно получать заново.
