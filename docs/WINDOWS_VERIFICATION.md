# Проверка на Windows — пока не выполнена

Цель: Windows 10/11, полный AutoCAD 2027, Python 3.11+, интерактивная сессия того же
пользователя и одинаковый уровень прав у AutoCAD и MCP. Проверять только на новых
тестовых документах. Не использовать рабочий DWG друга для первого запуска.

1. Установить сервер по README. Выполнить `.\.venv\Scripts\python.exe scripts\check_environment.py`.
   Убедиться, что видны pywin32 и зарегистрированный CLSID. Скрипт не подключается к AutoCAD.
2. Открыть AutoCAD вручную, дождаться готовности, закрыть модальные окна.
3. Зарегистрировать сервер в Codex, проверить `codex mcp list`, попросить статус и версию.
4. Создать новый тестовый документ. Проверить INSUNITS=4, линии, полилинии, окружность,
   дугу, прямоугольник, многоугольник, текст, MText, размер, сплайн и штриховку.
5. Проверить слои, их свойства, исходный блок с атрибутами и собственную 2D DWG-библиотеку.
   Для пользовательского блока проверить единицы, плоскость XY, атрибуты и масштаб.
6. Проверить `cad_execute_batch` с dry_run: чертёж не меняется. Затем выполнить пакет.
   Искусственно создать ошибку (отсутствующий тег блока), записать отчёт best_effort
   и проверить, какие объекты действительно удалены. Не считать Undo Mark транзакцией.
7. Запустить `examples\hvac_example.py --backend com --save hvac-test.dwg`, затем
   `examples\plumbing_example.py --backend com --save plumbing-test.dwg`.
   Убедиться, что элементы редактируются, а аксонометрия полностью плоская.
8. Перезапустить MCP, повторно подключиться к этим DWG, собрать сеть и спецификацию.
   Проверить XData, узлы на вершинах, длины в метрах и отсутствие повторного подсчёта.
9. Проверить подтверждения удаления и массовых изменений, запрет выхода за save_root,
   запрет перезаписи без разрешения, резервную копию перед разрешённой перезаписью.
10. Проверить PowerShell installer/uninstaller (`-WhatIf` первым), пути с пробелами,
    повторную установку, `-SkipCodexRegistration`, ошибки Python и отсутствие AutoCAD.

Отдельный автоматический COM smoke-тест подготовлен и **не запускался**:

```powershell
$env:ACAD_MCP_RUN_INTEGRATION = '1'
.\.venv\Scripts\python.exe -m pytest -m autocad -v
Remove-Item Env:\ACAD_MCP_RUN_INTEGRATION
```

Он создаёт новый документ, слой, блок, линию, полилинию, вставляет блок, читает объекты
и сохраняет DWG во временной папке pytest. Тестовый документ остаётся открытым.
Он не проверяет весь каталог tools: сплайн, штриховка, преобразования, пользовательские
блоки, XData, оба инженерных сценария и installer требуют отдельных проверок выше.

Сохранить версии ПО, отчёт pytest, журнал ошибок и сведения о частичных изменениях
в локальном отчёте. Передавать отчёт или DWG третьим лицам только с разрешения владельца.
